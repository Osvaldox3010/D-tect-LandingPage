# D-TECT — Landing Page (React + Vite)

Landing page de D-TECT — evaluaciones de control de confianza (poligrafía,
toxicología, psicometría, estudio socioeconómico y antecedentes penales).

📖 **Para instalar y correr el proyecto, ver [`INSTALL.md`](./INSTALL.md)** —
incluye requisitos, pasos de instalación, cómo reemplazar las imágenes,
cómo conectar el formulario a un backend real y cómo desplegar el sitio.

## Resumen rápido

```bash
npm install
npm run dev       # desarrollo → http://localhost:5173
npm run build     # genera dist/ para producción
npm run preview   # previsualiza el build de producción
```
